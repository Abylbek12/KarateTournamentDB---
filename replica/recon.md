# Карта Uventex (myuventex.com, веб)

Срез: весь цикл турнира: каталог → регистрация и оплата → категории → сетки → ринги и табло → результаты и рейтинг.
Для кого: Apsatarov (apsatarov.vercel.app), платформа турниров по каратэ в Кыргызстане. Сайт уже есть, карта показывает, чего не хватает.
Дата: 2026-11-19

Метод: только публичные страницы, смотрел их вручную. Вход в аккаунт организатора в панели браузера не сохранился,
поэтому экраны за входом (кабинет организатора, форма заявки, оплата) **не проверены**: в таблицах они помечены «не видел».
Публичные условия использования (Terms of Service) на сайте не нашёл, есть только Privacy Policy (2018).
Если у вас есть договор с Uventex как у организатора, проверьте, нет ли в нём запрета на конкурирующий продукт.

## Главный цикл

Организатор публикует турнир с категориями и ценами, клубы и спортсмены регистрируются и платят онлайн,
в день турнира секретари ведут бои на рингах, а зрители смотрят онлайн-табло, расписание и результаты.

## Сценарии

```
F01 Зритель находит турнир и смотрит категории
    S01 -> S04 -> S05
    кликов: 2
    edge: нет турниров в стране, турнир прошёл, другая валюта

F02 Спортсмен/тренер регистрируется на турнир (за входом, не проверено)
    S04 -> S02 -> S16 (выбор категорий, цена 1st + 2nd+ по текущему периоду) -> оплата -> S18
    кликов: ~6 (оценка)
    edge: регистрация закрылась по таймеру, сменился ценовой период, неверный возраст или пояс, неудачная оплата

F03 Организатор готовит турнир (не проверено)
    S19 -> категории и цены -> ценовые периоды -> S20 ринги -> сетки S07
    edge: пустая категория, один участник в категории, перенос категории на другой ринг

F04 День турнира: секретарь ведёт бой, зрители смотрят
    ринг (пульт Scorekeeper) -> S10 / S12 обновляются -> S09 / S08
    edge: ринг отстаёт, перенос категории, плохой интернет

F05 Судья подаёт заявку
    S04 -> S17
```

## Предполагаемая модель данных

```
Event       id, name, start_date, end_date, country, city, venue, sport, rating_system, type (SuperEvent / League / Sanctioning),
            registration_open_at, registration_close_at, currency, poster
            evidence: S01, S04, S05   confidence: high
PricePeriod id, event_id, starts_on, ends_on
            evidence: S05             confidence: high
Division    id, event_id, code (K001), class (individual | team | dual), type (Kobudo, Kata, Kumite...), age_group,
            gender (male | female | mix), rank_range ("Until Blue/Purple", "Brown to Black", "Open Grade"), weapon/discipline
            evidence: S05 названия    confidence: high
DivisionPrice division_id или event_id, period_id, first_price, additional_price
            evidence: S05 столбцы 1st / 2nd+   confidence: medium (неясно, цена у категории или у периода)
Ring        id, event_id, day, number ("Saturday #1")
            evidence: S10, S12        confidence: high
EventDay    id, event_id, date        evidence: S12 ?day=   confidence: medium
Entry       id, athlete_id, division_id, team_id, price_paid, status
            evidence: S14, S18        confidence: guess
Match       id, division_id, ring_id, order, red, blue, score, winner, status
            evidence: S10, S12        confidence: guess
Official    id, user_id, event_id, role (referee | scorekeeper | coordinator)
            evidence: S17, обучение по ролям   confidence: medium
Ticket      id, event_id, buyer, type, price   evidence: S15   confidence: guess
```

Связи: Event 1-n PricePeriod, Event 1-n Division, Division 1-n Entry, Event 1-n Ring, Ring 1-n Match, Event 1-n Official.

## Матрица функций

См. `features.csv`: 42 строки. Must 20, should 10, could 8, skip 4.
У Apsatarov уже есть почти весь «день турнира». Главные пробелы: **ценовые периоды, цена 1st/2nd+, онлайн-оплата, чек-ин расписание, билеты, заявки судей**.

## Вне среза (не клонируем)

- Studios и Virtual Studios: отдельные продукты Uventex для школ.
- База спортсменов Uventex и рейтинги чужих лиг (NASKA и др.): это их данные.
- Рекламный бизнес и брендированные магазины спонсоров.
- Uventex TV как свой видеосервис: у нас есть YouTube, этого достаточно.

## Размер

Экранов 26, сценариев 5, сущностей 10. Сложные части: онлайн-оплата (провайдер для Кыргызстана: Элсом / Mbank / FreedomPay, а не Stripe),
ценовые периоды с расчётом корзины, расписание и табло в реальном времени на многих экранах.
Размер: **M**, если закрывать только пробелы (несколько недель), потому что основа уже построена.
