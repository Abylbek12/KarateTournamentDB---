# Карта Sportdata SET Online (sportdata.org/karate/set-online, веб)

Срез: весь цикл турнира со стороны клуба: календарь → кабинет клуба → база спортсменов / тренеров / судей → заявка → корзина и оплата → результаты.
Для кого: Apsatarov (apsatarov.vercel.app). Сравнение — с текущим сайтом, где уже есть цены по периодам (см. `../recon.md` про Uventex).
Дата: 2026-11-19

## Условия использования — важно

Условия Sportdata (GTC) дают лицензию **только для личного использования** и запрещают коммерческое и «производное» использование сайта
и его содержимого, а также роботов для сбора данных. Прямого запрета строить конкурента нет, но формулировки широкие.
Поэтому кабинет смотрел только на главной странице (dashboard), глубже не ходил. Остальное — из публичной справки Sportdata.
Ничего из их текстов, оформления и кода не копируем: только то, **что** делает продукт.

## Главный цикл

Клуб один раз заводит спортсменов, тренеров и судей в своей базе и потом в пару кликов заявляет их на любой турнир,
оплачивает корзину организатору онлайн, а в день турнира всё идёт по программе SET Pro (сетки, табло, результаты, рейтинг WKF).

## Сценарии

```
F01 Клуб заявляет спортсмена на турнир
    S02 -> S03 (поиск) -> S04 -> S09 (согласие, 1-й раз) -> S10: спортсмен из базы + категория -> S11 оплата
    кликов: ~7, если спортсмен уже в базе (у нас сейчас — заново вводить ФИО, дату, вес, пояс каждый раз)
    edge: спортсмена нет в базе (переход в S05 и обратно), регистрация закрыта, ошибка категории, неудачная оплата

F02 Клуб заводит спортсмена один раз
    S05 -> «Добавить» -> данные (+ кю/дан, вес, рост, ID) -> фото -> сохранить
    edge: тот же спортсмен в двух клубах, фото с веб-камеры

F03 Клуб заявляет тренера / судью
    S06 или S07 -> профиль -> на событии вкладка тренеров / судей -> корзина

F04 Отзыв заявки
    S10 -> удалить заявку (бесплатно до конца регистрации; после — взнос обязателен)
```

## Матрица функций

См. `features.csv`: 37 строк.
Главный пробел по сравнению с Apsatarov: **база спортсменов клуба** (завёл один раз — заявляешь на любой турнир).
Дальше: согласие с положением, корзина с онлайн-оплатой, заявки тренеров и судей, аккредитации и сертификаты.

## Вне среза

- Sports-ID (членство в федерации), ТВ-графика: отдельные продукты.
- Официальный рейтинг WKF и статус «WKF approved»: принадлежат WKF и Sportdata.
- База турниров и пользователей Sportdata.

## Размер

Экранов 17, сценариев 4, сущностей 10. Сложные места: база спортсменов с переходом старых заявок (сейчас спортсмен хранится внутри заявки),
дети и персональные данные (фото, e-mail), корзина с оплатой (тот же шаг 2 из плана), один спортсмен в двух клубах.
Размер: **M** (несколько недель), большая часть — база клуба и корзина.
