# Apsatarov — турниры по каратэ

Сайт: https://apsatarov.vercel.app

Платформа для проведения турниров по карате (WKF / SKIF): витрина турниров, регистрация,
жеребьёвка и сетки, расписание татами, онлайн-табло, судейство и протоколы, медконтроль,
аналитика и ИИ-ассистент «Сенсей» (Claude). Интерфейс на русском, кыргызском и английском.

Стек: React 19 + Vite + Tailwind CSS (клиент), Express (сервер), Claude API от Anthropic (ИИ),
Postgres на Vercel или файл `db.json` на своём компьютере (данные).

Подробнее о структуре кода и правилах работы — в [CLAUDE.md](CLAUDE.md).
Как разместить сайт на Vercel без программирования — в [DEPLOY_VERCEL.md](DEPLOY_VERCEL.md).

## Запуск на своём компьютере

Нужен Node.js 22.

```bash
npm install
cp .env.example .env     # затем при желании заполните .env
npm run dev              # http://localhost:3000
```

При первом запуске в режиме разработки сервер создаёт администратора `admin@localhost`
и **один раз** печатает его пароль в консоль. Чтобы задать свой — заполните
`ADMIN_EMAIL` и `ADMIN_PASSWORD` в `.env` до первого запуска (или удалите папку `data/`).

Проверки перед коммитом:

```bash
npm run lint     # проверка типов
npm test         # жеребьёвка, поединки, категории, международные имена
```

## Запуск на сервере (production)

```bash
npm install
npm run build
ADMIN_EMAIL=you@example.com ADMIN_PASSWORD='надёжный-пароль' npm start
```

- Без `ADMIN_EMAIL`/`ADMIN_PASSWORD` в production администратор не создаётся.
- Сайт должен работать по HTTPS (за nginx/Caddy или на хостинге с HTTPS) — тогда cookie сессии помечается `Secure`.
- Папка `DATA_DIR` (по умолчанию `./data`) должна сохраняться между перезапусками и попадать в бэкапы.

## Запуск на Vercel

Сайт работает на Vercel, обновляется сам при каждом изменении в ветке `main` на GitHub.
Данные хранятся в Postgres (Neon): переменная `DATABASE_URL` появляется, когда база подключена
во вкладке Storage. Пошаговая инструкция — в [DEPLOY_VERCEL.md](DEPLOY_VERCEL.md).

## Переменные окружения

Полный список с пояснениями — в [.env.example](.env.example). Главные:

| Имя | Для чего |
|---|---|
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | главный администратор (обязательны в production) |
| `ANTHROPIC_API_KEY` | ключ Claude для ассистента «Сенсей»; без него ассистент не показывается |
| `CLAUDE_MODEL` | модель Claude (по умолчанию `claude-opus-5-5`) |
| `DATABASE_URL` | Postgres; если задана, данные хранятся в базе, а не в `DATA_DIR` |
| `DATA_DIR`, `PORT` | папка данных и порт для запуска на своём компьютере |

## Безопасность и роли

- Вход — по email и паролю; пароли хранятся только в виде хеша (scrypt).
- Сессия — HttpOnly-cookie, отдельная для каждого браузера.
- Права проверяет сервер: создавать, менять и удалять турниры может только администратор.
- При регистрации можно стать только тренером или спортсменом. Роли судей, секретаря, врача и
  администратора выдаёт администратор (`PUT /api/admin/users/:id/role`) в разделе «Турниры и пользователи».
- Личные данные спортсменов (дата рождения, вес, лицензия, оплата) видят только администратор,
  главный судья, судья татами, секретарь и врач.
- Вход через Google/Facebook пока отключён: для него нужен обмен кода на сервере.

## Что хранится на сервере

Турниры, аккаунты, сессии, картинки турниров, а также **участники, поединки, протоколы
и категории**. На своём компьютере это файл `data/db.json`, на Vercel — база Postgres.
И то и другое переживает перезапуск.

Эти данные общие для всех устройств. Если два устройства одновременно меняют одно и то же,
второе получит свежую версию и попросит повторить изменение (данные не перезаписываются молча).
Обновления приходят сразу, когда сайт запущен на своём компьютере или сервере; на Vercel
экраны сами спрашивают сервер: раз в 3 секунды, а список поединков (табло) — раз в секунду.

Кто может менять (`/api/state/:key`):

| Данные | Роли |
|---|---|
| Участники | администратор, главный судья, секретарь, врач; тренер и спортсмен — только добавлять свои заявки |
| Поединки | администратор, главный судья, судья татами, секретарь |
| Протоколы | администратор, главный судья, судья татами, секретарь |
| Категории | администратор, главный судья |

Гость видит данные, но его изменения остаются только в его браузере.

Пока **только в браузере**: настройки отдельных модулей (видеоаналитика, бухгалтерия, медконтроль и т.п.),
у которых своё внутреннее состояние.

## Резервные копии и работа без интернета

Администратор может скачать резервную копию и восстановить её («Турниры и пользователи»).
Это позволяет провести турнир в зале без интернета на ноутбуке-сервере и потом вернуть результаты на сайт.
Порядок действий — в [DEPLOY_VERCEL.md](DEPLOY_VERCEL.md), раздел «Турнир в зале без интернета».
