# Как разместить Tatami.kg на Vercel (бесплатно)

Инструкция для владельцев сайта. Нужен только браузер, программировать не нужно.
Всё делается один раз, примерно за 20–30 минут.

## Что понадобится

1. **Аккаунт GitHub** — там хранится код сайта.
2. **Аккаунт Vercel** — там сайт работает. Бесплатный тариф Hobby. Регистрируйтесь через кнопку «Continue with GitHub».
3. **База данных** — создаётся прямо внутри Vercel (вкладка Storage → Neon), отдельно регистрироваться не нужно.

> Бесплатный тариф Vercel предназначен для некоммерческого использования. Для клубного или
> федерационного сайта, где деньги через сайт не проходят, это подходит. Лимиты бесплатного
> тарифа смотрите в Vercel: **Settings → Usage**.

## Шаг 1. Код сайта у вас на GitHub

Попросите прежнего владельца **передать репозиторий** вам (GitHub → Settings → Transfer ownership)
или сделайте его копию себе: на странице репозитория кнопка **Fork**.

## Шаг 2. Создать проект на Vercel

1. Войдите на https://vercel.com через GitHub.
2. **Add New… → Project**, выберите репозиторий с сайтом, нажмите **Import**.
3. Настройки сборки менять не нужно — они уже лежат в файле `vercel.json`.
4. Пока **не нажимайте Deploy**: сначала шаг 3 и 4.

## Шаг 3. Подключить базу данных

1. В проекте откройте вкладку **Storage → Create Database → Neon (Postgres)**.
2. Регион базы выберите **Frankfurt (eu-central-1)**: сервер сайта тоже во Франкфурте, так быстрее всего для Кыргызстана.
3. Тариф **Free**. Нажмите **Connect** к этому проекту.
4. Vercel сам добавит переменную `DATABASE_URL` (или `POSTGRES_URL`). Больше с базой ничего делать не нужно: таблица создастся при первом открытии сайта.

## Шаг 4. Задать администратора

В проекте: **Settings → Environment Variables**, добавьте:

| Имя | Значение |
|---|---|
| `ADMIN_EMAIL` | email главного администратора |
| `ADMIN_PASSWORD` | надёжный пароль (не меньше 12 символов) |
| `ANTHROPIC_API_KEY` | необязательно: ключ Claude (console.anthropic.com) для ассистента «Сенсей». Без ключа ассистент на сайте не показывается. Каждый вопрос стоит денег по тарифу Anthropic |

Пароль никому не пересылайте в мессенджерах. После первого входа его можно сменить в личном кабинете.

## Шаг 5. Опубликовать

1. **Deployments → Redeploy** (или кнопка **Deploy**, если ещё не нажимали).
2. Через 1–2 минуты сайт откроется по адресу вида `https://имя-проекта.vercel.app`.
3. Войдите как администратор (email и пароль из шага 4).
4. Откройте **«Турниры и пользователи»** — там ссылки-приглашения для тренеров, спортсменов и судей.

Каждый раз, когда в GitHub появляются изменения кода, Vercel сам обновляет сайт.

## Шаг 6. Свой домен (по желанию)

**Settings → Domains → Add** и введите домен, например `tatami.kg`. Vercel покажет, какие записи DNS
прописать у регистратора домена. HTTPS включится сам.

## Как работает табло на Vercel

На Vercel нет постоянного соединения с сервером, поэтому табло, пульты и экран вызова сами
спрашивают сервер раз в секунду. Задержка для зрителей — около секунды. Часы боя идут точно,
одинаково на всех экранах.

## Турнир в зале без интернета

Если в зале нет интернета, сервером становится ноутбук:

1. На сайте (пока есть интернет): **Турниры и пользователи → Скачать резервную копию**.
2. На ноутбук установите Node.js (https://nodejs.org, версия LTS) и скачайте код сайта с GitHub
   (кнопка **Code → Download ZIP**, распакуйте).
3. В папке сайта откройте терминал и выполните:
   ```
   npm install
   npm run build
   npm start
   ```
   Перед первым запуском создайте в папке файл `.env` с двумя строками:
   ```
   ADMIN_EMAIL=ваш email
   ADMIN_PASSWORD=ваш пароль
   ```
4. Откройте `http://localhost:3000`, войдите и нажмите **Восстановить из копии…** — выберите скачанный файл.
5. Раздел **«Работа без интернета»** покажет адрес ноутбука в сети (например `http://192.168.1.5:3000`) —
   планшеты, телефоны и телевизоры подключаются к тому же Wi-Fi и открывают этот адрес или QR-коды.
6. После турнира скачайте резервную копию на ноутбуке и восстановите её на сайте — результаты появятся в интернете.

> На Vercel файл для восстановления должен быть меньше ~4 МБ (ограничение размера запроса).
> Обычно копия весит гораздо меньше; если турнир очень большой, напишите разработчику.

## Если что-то не работает

- **«База данных недоступна»** — проверьте в Vercel → Storage, что база подключена к проекту, и сделайте Redeploy.
- **Не получается войти администратором** — проверьте `ADMIN_EMAIL` / `ADMIN_PASSWORD` в Settings → Environment Variables.
  Администратор создаётся автоматически, только если в базе ещё нет ни одного администратора.
- **Ошибки сайта** — Vercel → проект → **Logs**.
